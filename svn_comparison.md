1. В Git ветвление «дешёвое», потому что ветка — это крошечный текстовый указатель на коммит, а в SVN «дорогое» из-за физического копирования папки с файлами.
2. Нет, в SVN нельзя сделать коммит без интернета, так как это централизованная система, требующая обязательного подключения к серверу для фиксации изменений.
3. SVN предпочтительнее Git при работе с огромными бинарными файлами, необходимости блокировки файлов от одновременного редактирования и для гибкой настройки прав доступа к отдельным папкам.
